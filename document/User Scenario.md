# 영화

### 영화 검색

- 영화명, 감독명, 배우명 조회
    1. 메인페이지에서 제목으로 영화를 검색한다.
    2. 제목에 검색어가 포함된 영화들의 포스터, 영화명, 상영여부, 감독명, 배우명을 보여준다.
    3. 상세보기 버튼을 누르면 상영시간 (러닝 타임), 영화 등급, 장르, 영화소개, 배급사, 개봉일까지 보여준다. 
- 개봉일, 인기순, 장르, 상영 유형 필터링
    1. 메인페이지에서 디폴트로 인기순으로 상영중 영화 or 14일 이내에 개봉하는 영화를 보여준다. 
    2. 필터링을 통해 해당 영화중 개봉일이 빠른 순, 장르, 상영유형에 따라 보여준다.
- 유저/어드민용 제공 기능이 달라야함
    - 관리 페이지를 따로 구분해서 어드민만 NAVBAR의 관리 탭 보여주기

### 영화 생성/수정/삭제

어드민에게만 NAVBAR의 관리 탭을 보여준다.

수정/삭제

1. 관리페이지에선 디폴트로 개봉이 느린 순으로 영화 리스트를 보여준다. 이때 영화명/감독명/개봉일과 함께 상세보기 수정/삭제 버튼도 같이 보여준다. 만약 상영일정이 남아있다면 삭제버튼을 클릭했을 때 상영일정이 남아있다는 실패UI를 보여준다.
2. 영화명/감독명으로 검색하거나 장르/상영유형 필터링도 당연히 가능하다. 
3. 삭제 버튼을 누르면 해당 영화정보가 삭제되고 다시 관리페이지로 넘어간다.
4. 수정 버튼을 누르면 해당 영화의 수정 페이지로 이동한다. 수정페이지는 영화 등록 페이지와 형식은 같고 기존 영화내용은 불러와야한다.
5. 수정이 완료되면 해당 영화 상세페이지로 넘어간다.
6. 실패시 실패 사유와 함께 실패UI를 보여준다.

생성

1. 관리페이지에서 영화 등록 버튼을 클릭한다.
2. 직접 입력: 영화명, 포스터, 상영시간(러닝 타임), 감독명, 배우명, 영화소개, 배급사, 개봉일
3. 선택 입력: 
    
    영화등급(ALL, 12, 15, 19), 
    
    상영유형(2D, 3D, 4D),
    
    장르(액션, 코미디, 드라마, 로맨스, 멜로, 스릴러, 공포 (호러), SF (공상과학), 판타지, 미스터리, 범죄, 어드벤처 (모험), 전쟁, 서부극 (웨스턴), 애니메이션, 다큐멘터리, 뮤지컬, 가족, 스포츠, 느와르, 시대극 / 사극, 정치 / 사회, 성장 (청춘), 재난, 음악, 심리, 법정, 추리, 역사, 바이오픽 (실존 인물 이야기)) ⇒ 회의할 때 걸러내
    
    배우 캐스팅 타입(주연, 조연, 특별출연)
    
4. 성공하면 등록한 영화의 영화 상세 페이지로 이동한다.
5. 실패시 실패 사유와 함께 실패UI를 보여준다. 

### 영화/감독/배우 상세페이지

영화 상세 페이지

1. 포스터, 상영여부, 감독명, 배우명, 상영시간 (러닝 타임), 영화 등급, 장르, 영화소개, 배급사, 개봉일을 보여준다.
2. 이때 감독명과 배우명을 클릭하여 감독/배우의 상세페이지로 이동할 수 있다.

감독 상세 페이지

1. 감독 사진, 감독명, 해당 감독의 필모그래피를 보여준다. 
2. 필모그래피는 개봉일이 늦은 순으로 보여준다

배우 상세 페이지

1. 배우 사진, 배우명, 해당 배우의 필모그래피를 보여준다.
2. 필모그래피는 개봉일이 늦은 순으로 보여준다.
- 영화의 경우 상영중이라면 예매하기 클릭 시 해당 영화가 선택된 예매 페이지로 이동

# 예매

### 예매하기

1. 메인페이지 OR 영화 상세페이지에서 예매하기 클릭 시 해당 영화의 상영일정을 보여주는 상영관별 상영일정 페이지로 넘어간다.
2. 상영관별 상영일정 페이지에서 상영관과 상영일정을 선택한다.
3. 고객 유형별(청소년, 성인, 경로, 우대) 인원수를 선택한다. 선택 완료 버튼을 누르면 좌석 선택 페이지로 넘어간다. 성인영화라면 청소년은 비활성화 된다. 한 번에 최대 5명까지만 예매할 수 있다.
4. 성인영화라면 오프라인에서 신분증 검사를 한다는 내용의 UI를 보여준다.
5. 남은 좌석보다 인원수가 많으면 해당 내용의 실패 UI를 보여준다. 
6. 인원수만큼 예매 좌석을 선택한다.  
7. 결제하기 버튼을 클릭하여 결제 페이지로 넘어간다. 좌석 점유 요청이 실패하면 실패UI를 보여준다.

### 예매 리스트 (전체 조회-마이페이지)

1. 마이페이지에서 예매 버튼을 눌러 예매 리스트 조회 페이지로 넘어간다.
2. 이때 결제된 예매 리스트만 보여주고 상영일정이 느린 것부터 보여준다. 이미 상영일정이 지난 영화는 구분하여 보여준다(회색 텍스트같은걸로)
3. 각 예매내역은 영화 포스터, 영화명, 상영관, 좌석번호, 총가격을 보여준다. 이때 환불 버튼도 같이 보여준다.
4. 환불버튼 ⇒ 예매 취소

### 예매 리스트 (비회원 예매내역 조회)

1. 로그인을 하지않은 상태에서 예매 탭을 클릭한다.
2. 비회원 정보로 예매내역을 확인할 수 있다.(이 페이지에서 회원 로그인도 할 수 있음)
3. 비회원 정보: 이름, 생년월일, 휴대폰번호, 예매 비밀번호(4자리 숫자)

### 예매 취소하기

1. 결제 취소 요청이 실패하면 사유와 같이 실패 UI를 보여준다.
2. 결제 취소 요청이 성공하면 성공UI를 보여준다.

# 상영관

### [관리자] 상영관 생성/수정/삭제

상영관 관리 페이지

1. 상영관 관리 메뉴를 선택하여 상영관 목록을 확인한다.

상영관 생성 페이지

1. 상영관 생성 버튼을 클릭한다.
2. 상영관 번호, 이름, 규격을 입력한다.
3. 좌석 생성 페이지로 이동한다.

상영관 수정 페이지

1. 상영관 수정 버튼을 클릭한다.
2. 상영관 번호, 이름, 규격 중 수정이 필요한 것을 수정한다.
3. 특정 좌석 수정이 필요하면, 좌석 수정 버튼을 클릭해 좌석 수정 페이지로 이동한다.

상영관 삭제

1. 상영관 삭제 버튼을 클릭한다.

### [관리자] 좌석 생성/수정/삭제

좌석 생성 페이지

1. 상영관 생성 페이지로부터 넘어오면, 자동으로 좌석이 생성된다.
2. 사용 불가능한 좌석을 선택한다.
3. 삭제할 좌석을 선택한다.

좌석 수정 페이지

1. 상영관 수정 페이지로부터 넘어오면, 좌석 정보가 보여진다.
2. 사용 불가능한/가능한 좌석을 선택한다.
3. 생성/삭제할 좌석을 선택한다.

### [고객/관리자] 상영관 상세페이지

1. 상영관 리스트를 클릭한다.
2. 상영관을 클릭한다.
3. 상영관의 상영 일정과 좌석 정보를 표시한다.

# 결제

### 결제하기

1. 보유 포인트에서 사용할 금액을 직접 입력하거나, 최대 사용 버튼을 클릭한다.
2. 카드/계좌이체 중 결제수단을 선택한다.
3. 보유한 제휴사 카드 할인을 선택한다.
4. 총 결제 금액을 확인하고, 차감/적립 포인트를 확인한다.
5. 결제하기를 클릭하면 결제 API가 호출되고, 결제를 수행한다.
6. 결제 성공 시 예매 완료 페이지로 이동하고, 티켓 정보를 출력한다.

### 환불하기

1. 마이페이지에서 예매내역으로 진입한다.
2. 환불 가능한 예매 건을 확인한다. 상영 시작 시간 기준으로 환불 가능 여부가 표시되어 있다.
3. 환불 버튼을 클릭한다.
4. 환불 정책을 확인한다. 시간에 따라 환불 수수료 발생 여부를 안내한다.
5. 최종 환불 버튼을 클릭한다. 결제 수단으로 환불되며, 포인트도 원복된다. 환불 완료 후, 티켓의 상태가 취소됨으로 표시된다.

# 상영 일정

### 상영 일정 생성/수정/삭제

- 상영 일정 관리 페이지에서 상영 일정에 대한 관리가 가능하며, 관리자만이 접근 가능한다.
    - 관리 페이지의 영화 리스트에서 상영 일정 관리 버튼을 통해 접근할 수 있다. 이 경우 해당 영화가 선택되어진 상영 일정 관리 페이지가 제시된다.
    - 네비게이션 바의 관리 카테고리의 하위 카테고리 중 상영 일정을 클릭하여 접근할 수 있다.
- 상영 일정 관리 페이지에는 캘린더와 현재 상영 예정 일정이 존재하는 모든 영화 리스트, 검색 바가 제시된다.
    - 캘린더에 날짜가 지난 경우와 상영 일정이 존재하지 않는 경우 희미하게 표시되며, 상영 일정이 존재하는 날의 경우에만 진하게 표시되어있다.
    - 존재하지 않는 영화의 경우에는 검색바에서 검색하여 선택 가능하다.
- 날짜와 영화를 선택하면 해당 조건에 맞는 상영관별 상영 일정이 타임 테이블로 제시된다.
    - 상영관은 번호에 따라 정렬되어 제시되며, 선택된 상영관 외에는 토글로 상세 내용 (타임 테이블)이 제공되지 않는다.
    - 타임 테이블에는 상영 일정에 해당하는 타임라인이 파란색으로 칠해져있으며, 영화 이름과 상영 회차, 상영 시작 시간, 종료 시간이 타임라인 박스 내부의 상단에 제시된다.
    - 영화 이름을 클릭하면 해당 영화의 상세페이지로, 상영관을 클릭하면 상영관 상세 페이지로 이동한다.
    - 수정이 불가한 상영 일정의 경우 희미하게 표시되며, 수정 가능한 상영 일정의 경우에만 active하게 (클릭 가능)하게 수정/삭제 버튼과 함께 제시된다.
- 기능 수행
    - 생성하기
    - 수정하기
        - 수정하고자 하는 상영 일정을 클릭하면 상영 일정 수정 팝업 창이 제시된다.
    - 삭제하기

### 예매 페이지 (cgv 참고)-예매, 상영일정 관리

- 상영일정이 존재하는 모든 영화 리스트 & 날짜 제공

# 고객

### 회원가입

1. 사용자가 회원가입 페이지에 접근한다.
2. 이름, id, password, 생년월일을 입력한다.
3. id, password정책을 통과하고 이름, id의 중복검사를 통과하면 회원가입 버튼이 활성화 된다.
4. 회원가입에 성공하면 로그인된 상태로 메인페이지로 이동한다.

### 로그인-회원, 어드민

1. 로그인 페이지에서 id와 password를 입력한다.
2. 일치하는 고객이 있으면 로그인에 성공하고 메인페이지로 이동한다.

### 로그인-비회원

1. 비회원 로그인 페이지에서 이름, 전화번호, 생년월일, 비밀번호를 입력한다.
